# 0002. ModalOutlet 挂在路由树内部

日期: 2026-08-19
状态: 已接受

## 背景

命令式弹窗需要一个全局挂载点(`ModalOutlet`)把 store 里的实例渲染出来. 它可以挂在
`AppRouter` 的 `<App>` 下与路由出口平级, 也可以挂进路由树内部.

## 判据

`AppRouter` 用 `<RouterPage key={i18n.language} />` 让整棵路由树在切语言时重挂载, 好让各处直接调用的
`$t` 重新取值(见 AGENTS.md). 挂载点若放在路由出口**外面**, 切语言时它不重挂载,
弹窗里的文案就不会跟着变 —— 与全项目唯一的语言订阅机制脱节.

所以挂进路由树内部, 随之一起重挂载.

## 代价

**弹窗生命周期被路由绑住**: 切语言会关掉当前打开的弹窗. 未结算的 Promise 全部 resolve `undefined`,
等同用户取消(实现见 `modalStore.discardAll`) —— 不能让它们悬挂, 那是静默失败.

这与 AGENTS.md 已经接受的"重挂载会丢组件内部 state"是同一笔代价, 切语言是低频操作.

**跨路由弹窗做不了**. 目前没有这种需求; 真出现时要重新审视本决策.

另一面: 挂载点消失不影响 `open()` 的可用性 —— store 才是事实来源, 挂载点只是显示器,
挂载之前调用的 `open` 会在它挂上来之后补渲染.
